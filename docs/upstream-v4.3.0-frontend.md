# v4.3.0 前端整合

整合基线：中文版 `43bb33e1`，上游 `v4.3.0` / `77f7b3bd`。
本次实际合并包括上游前端和关联 shared/server 实现，不再只是增加 Props 声明。

- 高德继续按中国大陆区域自动切换，保留 MarkerCluster 2.0 的默认聚合圆圈及单点点击。
- `amapTripLayers.ts` 绘制风险区域、Dawarich 轨迹、接入路线、路线统计、自驾途经点、日界和备选路线；复用共享坐标转换、轨迹筛选、风险弹窗及日界拖动逻辑。
- 途经点句柄独立于路线重绘，拖动结果返回 WGS-84。支持途经点删除、地图 POI 拖放和显式路线范围聚焦。
- 默认地图、GL、高德统一返回 `MapController`；移动端及 GL 加载/失败时的 Leaflet 回退也遵循此接口。
- 12306 查询、经停站应用、汽车经停点和同行人使用各自状态；过期查询不能覆盖新车次、类型或重新打开的预订，地点搜索不会保留上一个提供商的标识。
- 保留 Stage 1 的 176–242 迁移桥和缓存 provider 隔离；Stage 2 的高德、12306 域服务接入上游 Nest 模块，地点身份字段随保存、行程复制和收藏复制保留。

验证使用 Node 24，包括 shared/client/server 类型检查、server 测试类型检查、shared/client/server 构建，以及地图、预订表单、移动端、迁移桥、中文域服务和地点/收藏/行程服务的相关回归测试。定向 ESLint 无错误，仍有 SDK 边界的 `any` 和 Hook 依赖等警告；新增/主要改写地图文件通过格式检查。

外部高德 SDK、真实 12306 响应未使用生产凭据实测；自动化测试使用 SDK 和 HTTP 替身。Stage 4 继续负责真实服务验收、Docker 多架构双仓流水线适配及独立审查。本次 Docker 发布工作流保留中文版双仓版本，没有替换成上游单仓发布。
